# 邮箱验证码邮件配置

普通注册账号需要邮箱验证码；评委测试账号和游客直接使用方式保持不变。验证码有效期为 10 分钟、每个地址 60 秒可重新获取，错误尝试最多 5 次。服务端只保存带随机盐的验证码摘要，验证成功或过期后删除。

## 配置

在服务端私有 `.env` 或系统环境变量中配置，不要使用 `VITE_` 前缀，也不要把授权码提交到代码库：

```dotenv
SMTP_HOST=邮件服务商提供的SMTP主机名
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=完整邮箱地址
SMTP_PASSWORD=邮箱服务商生成的SMTP授权码
SMTP_FROM=维衡 AI <完整邮箱地址>
```

请从所选邮箱服务的管理页面确认 SMTP 主机、端口、安全连接方式和授权码。SMTP_PASSWORD 通常是单独生成的应用授权码，不应填写邮箱登录密码。修改线上服务器的配置后需要重启应用服务。

生产环境缺少上述必要配置时，验证码接口会明确报错，不会创建注册账号，也不会假称邮件已发出。邮箱授权信息只能放在服务端环境文件中，并限制文件权限；不能放进浏览器、前端构建产物、截图或日志。

## 本地调试

本地服务器没有配置 SMTP 时，只有从 `localhost` 回环访问且 `NODE_ENV` 不是 `production` 才返回一次性调试验证码。注册页面会标为“本地调试验证码”。该方式只用于本机联调；公网生产环境绝不会返回验证码。

配置 SMTP 后，本地同样会实际发送邮件。可先使用自己的邮箱注册并确认登录后资料可同步，再将同一组 SMTP 配置安全地加入线上服务器。
