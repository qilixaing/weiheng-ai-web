# AI 营养估算数值契约

- 食物目录中的已知营养值按每 100 克可食部保存；真实的 `0` 是有效数值。缺失字段保持未知。
- 当前模型对缺失的宏量营养字段只返回一项代表性**单值估算**，同时给出做法假设。它不是数据库检测值，也不是统计置信区间。
- 历史估算可能含 `low`/`high` 两端。读取旧快照时按两端中点转换为单值，保留“AI 估算”标记和原有假设；不把两端解释为置信区间。新模型输出的两端格式会被拒绝并重试。
- 程序把每 100 克数值按实际可食部克数换算、求和。目录值、AI 估算与未知项分别计数；缺失项不补零。已记录摄入与个人参考值分开展示，单日不完整记录不用于判断长期不足。
- 修改食物身份、克数或日期后，旧分析版本失效，重新计算后才能展示与当前记录一致的结果。
