# 维衡 AI 自愿试用操作说明

本说明用于收集真实可用性反馈，不能证明减重、疾病改善或医疗效果。模拟反馈均为虚构，只用于功能演示和测试。

## 参与及数据范围

邀请自愿参与的成年目标用户。说明任务、记录方式、保存位置及是否会分享脱敏结果，不要求录入真实身体指标。使用演示或自行编制的任务条件亦应注明。不同参与者用不同匿名编号；同一人的多次提交不能当成多位用户。

应用内反馈保存在当前浏览器当前使用空间，不自动上传，系统不验证独立参与者身份。不得把自愿提交条数直接写成独立用户人数。真实反馈也不等于已经完成独立研究核验。

## 建议任务

1. 档案完整的参与者，输入一餐预算、两项回避食物，以及真实确认过的备选食物、份量和价格，生成并核对方案。
2. 跳过整个档案，确认仍可查食物及安排一般餐食；没有成人营养配额。
3. 缺少菜价，检查价格待确认，不出现预算满足承诺。
4. 调整忌口，检查方案是否继续遵守；复杂菜式须核对配料。
5. 方案确认后进入草稿，核对重复点击不重复添加；实际食用后再保存饮食记录。
6. 查找一条食物的原始来源、生熟和单位，判断缺失值是否被清楚标注。

## 记录方法

明确开始/结束条件后用计时器记录真实用时，没有测量则留空。记录成功、失败、中断、原因、设备与网络条件。说明是否需要研究人员协助，不把帮助后完成与独立完成混算。

如果比较手工与网站，应固定相同任务，记录顺序效应及熟练度差异，交替顺序或如实说明未控制。不得用假数据生成实际效率提升、满意度或医疗结论。

## 汇总与导出

填写空白CSV模板，统计实际参与者数量、任务数量、有效用时样本数与完成比例。页面CSV仅包含当前空间自愿提交的反馈；没有集中后台汇总。分享前删除可识别信息，不附带身体档案、饮食明细、照片或聊天。

无真实试用时应写“尚无真实试用数据”。模拟反馈CSV必须标记“模拟用户反馈，非真实试用结果”，不得合并进真实汇总或作为参赛实证。
