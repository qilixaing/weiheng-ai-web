# 维衡 AI 本地改造交付

预览：[http://localhost:4173/](http://localhost:4173/)。本次只修改本地，未部署云端，未清空既有真实记录。

## 使用重点

1. 在“膳食方案 → 安排我的下一餐”填写日期、餐次、预算、回避项、偏好和可选运动情况；可以检索具体食物，填入份量及自己已知的价格。
2. 点击生成后，界面只显示真实完成的读取、检索、详情、计算和比较步骤。营养值由程序计算；缺失保持未知，没有价格时不能确认满足预算，没有菜单时不声称食堂在售。
3. 核对来源并调整克数或移除食物；确认后只加入草稿。实际吃过后到“饮食记录”保存；生成方案本身不等于实际食用。修改条件或目标可重新规划，回避项与备选条件会继续提交。
4. “食物浏览”可搜索全部2300条记录，每页12条。155条有逐条绑定的本地照片；其余搜索结果按该食物原始名称联网查开放许可候选，不用同类图顶替。未找到合格图片时会显示无照片状态。独立图库有1055张参考照片，每页24张，数量不代表逐条覆盖营养记录。
5. “关于”提供参考资料登记、真实自愿反馈、主动加载的30条模拟反馈、分别导出、试用说明和重置确认。真实反馈没有后台汇总；提交次数不代表独立用户人数。
6. 年龄保留0—120岁，身体档案可以整体跳过。19—78岁之外或档案不完整时不计算成人能量及供能配额。手机导航保留两行四列。
7. 对话记忆默认开启，保留最近50轮的文字范围；另受安全长度上限约束，不包含附件。轮数设置不在界面展示，仍可关闭记忆。

## 数据与素材

- 实际目录2300条，其中2227条有可追溯的USDA营养来源；扩展样本保留原始英文描述，中文仅为食材类别提示，尚未逐条完成中文品种细名翻译。
- 新参考图库1055张，经编号联系表审图，保留作者、原图、开放许可及处理说明。另有155张逐条绑定的开放许可食物照片；不再把一张家族照片批量显示在许多营养记录上。详细分类、缺失字段、匹配问题与后续方向见 CAMPUS_FOOD_COVERAGE.md。
- 食物浏览显示全部2300条数据；仅155条离线显示逐条绑定照片，其余卡片按食物名称查询 Wikimedia Commons 开放许可候选。候选可能有品种和加工状态差异、也可能找不到；网站明确标注并提供来源，不伪称已完成全量照片核对。筛除了27个明显状态不匹配的本地图片，并修正了“CORNED BEEF”误标成玉米的问题。
- 中国食物成分表只登记核实书目，正文及具体成分数据待有权限资料接入。DRIs沿用原项目公开成人参考映射；膳食指南只接入公开原则摘要。运动营养教材缺具体书名、作者、出版社和版本，尚未接入。

## 隐私与隔离的真实能力

- 账号经现有后端会话确认后进入不同本地命名空间；档案、对话、附件、报告和反馈按空间保存。访客沿用原有存储键，不自动迁移或删除旧记录。
- 当前Vue工作台仍主要在浏览器本地保存，未新增云端档案同步。不同设备、localhost与域名、不同端口的本地数据不会自动互通。共用同一个访客空间的人无法自动区分；可使用独立账号空间或浏览器配置文件。
- AI接收本次必要档案、条件与勾选的记录；特殊安全标记需单独选择发送。正文备注、记录照片、完整对话不自动附到规划请求。
- DeepSeek密钥仅由服务端私有环境加载。前端构建不读取环境文件；私密配置HTTP访问返回403，最终包已检查无实际密钥。
- 重置仅面向当前空间，需明确确认；本次没有对真实空间执行重置。
