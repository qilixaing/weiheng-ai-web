# 本地 AI 食物营养估算

`src/data/aiFoodEstimates.json` 保存目录食物缺失的主要营养范围。每项按每 100 克可食部保存热量、蛋白质、碳水和脂肪中原数据库缺少的字段；原数据库已有的数字保持原样。估算带有模型、时间和做法假设，不能当作实验室检测或标准成分表数值。

2026-11-04 使用服务端 DeepSeek 对 1,168 条缺少主要营养字段的目录食物生成估算范围。已逐批校验数值边界并写入文件；无条目失败。浏览器详情直接读本地数据，无需逐项联网生成。每日记录分析也优先读同一份数据，并按实际克数换算；自定义食物或没有覆盖的项目仍可按需请求 AI。

若用户补充具体配方并选择重新估算，AI 会根据本次输入重新计算，不会改写共享食物目录。批量更新脚本 `scripts/enrich-food-estimates.mjs` 支持续跑，调用入口需在本机服务进程临时设置 `WEIHENG_LOCAL_FOOD_ESTIMATE_BATCH=1`；默认关闭批量接口。运行前请先确认 `http://localhost:4173` 指向本地维衡 AI 项目，脚本每批提交后立即保存进度。

数据仅保存在项目代码中；当前浏览器本地使用。把项目部署到另一台服务器后，需要将该 JSON 文件一并构建部署，估算才会在该服务器可见。
