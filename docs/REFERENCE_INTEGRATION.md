# 参考资料接入说明

运行时登记见 `src/data/referenceRegistry.js`，食物成分来源与人群营养参考量、解释原则分开存储。

| 资料 | 本次实际接入范围 | 待补充 |
| --- | --- | --- |
| USDA SR28，2016年5月修订 | 官方ABBREV原始字段，原始NDB编号及英文描述 | 中国本地配方、品牌与菜式不能按名称自动套用 |
| 中国食物成分表标准版第6版 | 仅核对公开书目介绍 | 有使用权限的具体册次、条目、页码及原始数据；未导入整书 |
| DRIs 2023 | 沿用并展示原项目公开成人参考表映射，未新增书中数值 | 特殊人群不生成个体处方，需专业核对 |
| 中国居民膳食指南2022 | 官网公开八准则的简短文字摘要 | 未复制受限图形、图表或整书内容 |
| 运动营养教材 | 未接入，书目待确认 | 完整书名、作者、版次、出版社、具体章节和授权内容 |

导入资料时必须填写下面的模板字段。EAR、RNI、AI和UL含义不同，UL不是推荐目标；每100克、每天、每周以及RAE/RE、DFE/食物叶酸不可随意互换。原始数据缺失保持null。书目登记不能作为“已经引用该书某数值”的证明。

## 导入模板

```json
{"referenceId":"待填写","title":"待填写","edition":"待填写","volume":"待填写","locator":"真实章节/页码/条目编号","population":"适用人群","basis":"每100克可食部/每天/每周","unit":"原始单位及定义","value":null,"sourceUrl":null,"verifiedAt":null,"permission":"实际使用许可","status":"pending"}
```

不在没有出处时补页码、营养值或教材结论。公开网页可查阅不等于整本教材或图形可自由复制。
