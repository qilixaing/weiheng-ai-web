# 食物照片与授权

食物列表和详情使用按 foodId 匹配的实物参考照片，不再复用整类食物示意图。

## 对应食物照片

- 189 个现有条目中，182 个具体食物条目已匹配照片，共 157 张不同照片；同一食材的不同生熟条目可能共享参考照片。
- 本地文件：assets/food-photos/。照片最长边 640px，合计约 9 MiB；页面懒加载，使用异步图片解码。
- 映射清单：src/data/foodPhotoSources.json。完整归档：assets/food-photos/image-sources.json。
- 来源为 Wikimedia Commons，逐图保留作者、原文件页、许可链接和修改说明。采用 CC0、公有领域、CC BY 或 CC BY-SA，没有使用 NC/ND 限制照片。
- 详情页及浏览页「数据口径与图片署名」中可查看署名。CC BY-SA 图片的缩放、压缩或裁切版本继续遵守原许可；应随分发保留上述清单及许可链接。
- 图片展示食材主体，不证明具体品种、烹调方式或营养含量；照片与营养数据各自标明来源。婴儿胡萝卜泥、强化婴儿米粉等使用原料参考图时，图片说明明确差异。
- 七个未明确主体的旧目录（其他蔬菜、水果、主食、全谷物/杂豆、奶类、肉蛋豆制品、水产品）使用中性占位，不用其他品种照片冒充。
- 图片失效时显示占位和提示；不退回无关分类照片。运行时无需图库 API 或额外密钥。

来源和复用说明：
- https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
- 各照片的实际许可、作者和原页以逐图清单为准。

## 分类总览照片

原有 20 张分类照片继续用于分类总览，具体路径见 src/data/foodCategories.js。它们表示分类，不用作列表中的具体食物照片。

分类照片均为真实照片，来自 Wikimedia Commons，逐图署名见分类资产 image-sources.json。没有使用 HowToEat 站点照片或 AI 生成照片。原有 20 张照片为 800 × 600 JPEG，总计约 1.57 MiB。

## 更新流程

新增具体食物图片时，应先核对照片主体与食物名称，再核对原页作者和授权，压缩为网页尺寸，补全上述两个 JSON 的条目。不要把图片检索词直接作为已验证的匹配结果。
